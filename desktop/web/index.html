連上你的 iPhone

產生 QR code 中…
  1. 手機打開芹查 app，按「掃描電腦上的 QR code」掃左邊這個（用相機 app 掃也可以）
  2. 在 app 裡按「開始投影」，再按「開始廣播」
  3. 手機畫面就會出現在這裡。之後可以直接從控制中心的螢幕錄影按鈕開關
連不上？
  • 手機和電腦要連同一個 Wi-Fi（或電腦接同一台路由器的網路線）
  • 第一次執行時 Windows 會問要不要讓 Node.js 通過防火牆，要勾「私人網路」並允許。按錯了的話，到「Windows 安全性 → 防火牆 → 允許應用程式通過防火牆」把 Node.js 的「私人」打勾
  • Windows 的 Wi-Fi 網路類型要設成「私人網路」，設成「公用」會被擋
  • 上面的位址有好幾個時，選跟手機同一段的那個（通常是 192.168 開頭），再重掃一次
  • 手機 app 第一次會問「要尋找區域網路上的裝置」，要按允許

開始測試後整段都會錄起來。遇到問題按插書籤（或踩踏板），畫面不會跳走，繼續測就好。

測完按結束測試，再一個一個書籤框選、寫說明，最後一起送給 Claude。

沒開始測試就按插書籤，會自動開始一場，並把前 20 秒補進來。
