# 芹查

iPhone 真機測試回報工具。手機畫面即時投到 Windows 電腦，遇到問題在電腦上框選、劃線、寫字，直接交給 Claude Code 修。

名字取「勤查」的諧音，蔬菜系列用芹菜。

```
iPhone（芹查 app＋螢幕廣播）──Wi-Fi──▶ 電腦上的芹查 ──MCP──▶ Claude Code
   操作任何 app                        即時畫面、保留最近 20 秒      讀回報、修程式、標記已修好
                                       標記 → 框選 → 寫說明
```

## 每天怎麼用

1. 雙擊桌面的「芹查」，瀏覽器會打開 `http://localhost:7790`
2. 手機打開芹查 app，按「開始投影」→「開始廣播」
3. 電腦右邊選「這次測哪個 app」，按 **F9 開始測試**。整段都會錄起來，錄多久都行
4. 切到你要測的 app，照平常那樣操作。遇到問題按 **F8**（或踩踏板）插一個書籤，畫面不會跳走
   - 電腦下方會跳出一個小輸入框，打幾個字按 Enter 就記在這個書籤上，免得等一下忘記；不想寫就按 Esc 或直接繼續踩下一個
   - 懶得打字：輸入框出現後按 **Win+H**，用講的（Windows 內建語音輸入）
5. 測完按 **F9 結束測試**，自動進到排查畫面：
   - 右邊列出所有書籤，點一個就跳到那一刻
   - 書籤常常比你看到問題晚 1、2 秒：拖時間軸上的紅色書籤，或用 ← → 找到正確那一格按 **M**，就能把書籤移過去（插書籤時也會自動往前推 1 秒，設定頁可改）
   - 在畫面上用方框、圓圈、箭頭、手繪、文字標出問題，下面寫說明
   - 按 **N**（或 Ctrl+Enter）跳到下一個書籤
   - 書籤以外的地方也能拉進度條自己找，畫下去或寫說明就會多一筆
   - 寫到一半關掉也沒關係，草稿會自動存
6. 全部寫好按「全部送出」，再按「複製給 Claude」貼到 Claude Code，或按「用 Claude Code 開啟」
   - 只會送還沒送過的；之後回去翻錄影再補幾筆，第二次送出時交給 Claude 的話只會列這次的新編號，不會叫它把前面的重做
7. Claude 修好後，回報會變成「已修好，待驗收」。手機裝上新版、切到同一個畫面，在回報頁左右對照，按「通過，結案」或「還沒好，退回重修」

想當下就框選也行：測試中按「邊錄邊框選」，錄影會在背景繼續。沒按開始測試就先按 F8，會自動開始一場，並把前 20 秒補進來。

### 排查畫面的快捷鍵

| 按鍵 | 作用 |
|---|---|
| N／Shift+N | 下一個／上一個書籤 |
| M | 把選中的書籤移到目前這一格 |
| ← → | 上一格、下一格（加 Shift 一次跳 10 格） |
| 空白鍵 | 播放／暫停 |
| Enter | 跳到說明欄 |
| Ctrl+Enter | 寫完說明，跳到下一個書籤 |
| V R C A P T | 選取、方框、圓圈、箭頭、手繪、文字 |
| I／O | 設定區間起點／終點（動畫、轉場問題用，連續畫面會從這段取） |
| Delete | 刪掉選取的標註 |
| Ctrl+Z | 復原 |
| Shift＋拖曳 | 畫正方形、正圓 |

### 專案怎麼對應

每場測試開始時選「這次測哪個 app」，那場的回報都算它的。手機的螢幕廣播不會告訴電腦你開的是哪個 app，所以這裡要你自己選；選過會記住。

選單裡的 app 是芹查自己找的：每次啟動時掃描你的使用者資料夾和 D: 之後的磁碟，找出有 git 的資料夾，再只挑 iOS app（有 Xcode 專案、XcodeGen 的 project.yml、Expo 或 Flutter 的 iOS 設定）。網站、腳本之類的 vibe coding 專案不會出現。開了新的 app 專案，下次啟動芹查就會出現在選單；不想等就到設定頁按「重新掃描電腦上的 app」。名稱預設是 repo 名稱，可以在設定頁改成你習慣的叫法。

Claude Code 在哪個資料夾打開，芹查就從那個資料夾的 git repo 判斷是哪個專案，只給它那個 app 的回報。例如在 `qieji-app` 資料夾開 Claude Code，它只會看到茄記的回報；開錯資料夾時，它讀到別的 app 的回報會先警告你。

第一次在某個專案資料夾用過芹查的工具，芹查就會記住那個資料夾，之後「用 Claude Code 開啟」就知道要開哪裡。芹查不認得的 repo 會自動新增成一個專案。

### Claude 收到什麼

每筆回報 Claude 會拿到：

- 你的說明、嚴重度、專案
- 標註的位置（百分比座標）和你寫在圖上的字
- **框選處放大圖**、**整張畫面＋標註**、**問題前後的連續畫面拼圖**（看動畫、轉場、手勢問題用）
- 被退回過的話，還有你驗收時拍的「修改後」畫面和你的意見

每筆回報都有時間戳（在錄影的第幾分幾秒、是第幾個書籤）。整場測試只有一支錄影：結束測試後芹查會在背景把它轉成一個 MP4（安裝時會自動下載轉檔用的 ffmpeg），檔案位置會跟著回報一起給 Claude，「測試場次」頁也能直接看。Claude 看不了影片，所以芹查除了附上問題前 3 秒到後 1 秒的連續畫面，還讓 Claude 自己翻錄影：上下文不夠時，它可以指定時間範圍抓畫面來看。還有回報沒結案的錄影不會被自動刪掉。

Claude 能用的工具：

| 工具 | 作用 |
|---|---|
| `celery_list_notes` | 列出待修回報（預設只列目前資料夾那個 app 的，也可指定某一場測試） |
| `celery_get_note` | 讀一筆回報的文字和圖 |
| `celery_get_frames` | 翻測試錄影：指定時間範圍抓畫面（Claude 看不了影片，用這個看前後的操作） |
| `celery_get_session` | 看整場測試：書籤時間、當下寫的字、所有回報、整場取樣畫面 |
| `celery_mark_fixed` | 修好後標記，寫下改了什麼 |
| `celery_comment` | 看不懂時留言問你 |
| `celery_screenshot` | 截手機現在的畫面 |

## 安裝

### 電腦端（一次）

1. 裝 [Node.js](https://nodejs.org)（LTS 版）
2. 雙擊 `安裝芹查.cmd`：安裝套件、把芹查加到 Claude Code、在桌面建捷徑
3. 雙擊桌面的「芹查」啟動。第一次 Windows 會問防火牆，**勾「私人網路」並允許**
4. 到「設定」頁把你的專案加進去（名稱、GitHub repo、電腦上的資料夾）

想匯出 MP4 的話要另外裝 ffmpeg，沒裝也不影響其他功能。

### 手機端（一次）

手機 app 跟你其他 app 一樣走 GitHub Actions 編譯、上傳 TestFlight。步驟在 [`docs/TestFlight上架步驟.md`](docs/TestFlight上架步驟.md)，比平常多一步：要註冊 App Group。

裝好後打開芹查 app，掃電腦上「即時畫面」頁的 QR code 就配對完成。之後不用再掃，除非你在電腦上換了配對碼。

## 連不上的時候

| 狀況 | 原因和處理 |
|---|---|
| 手機 app 顯示「連不到」 | 手機和電腦要在同一個 Wi-Fi；電腦上的芹查要開著 |
| 一直連不到 | Windows 防火牆擋住了。到「Windows 安全性 → 防火牆與網路保護 → 允許應用程式通過防火牆」，把 Node.js 的「私人」打勾。Wi-Fi 的網路類型也要是「私人」 |
| QR code 上的位址不對 | 電腦有好幾張網卡時（VPN、WSL、虛擬機），在 QR code 下面的選單選 192.168 開頭那個，手機重掃 |
| 投影一開始就停了，說要先配對 | 還沒掃 QR code，或掃完沒存到（重新掃一次） |
| 畫面卡卡的 | 手機 app 把格數調到 15、畫質調成標準；或電腦改接網路線 |
| 踏板踩了沒反應 | 踏板要跟**電腦**配對，不是手機；芹查的瀏覽器分頁要是目前的視窗。到「設定」頁按「＋ 新增按鍵」再踩一下，就會記住踏板送的鍵 |
| 「用 Claude Code 開啟」按鈕沒出現 | 芹查還不知道那個 app 在電腦上的哪個資料夾。在那個資料夾開一次 Claude Code、用過芹查的工具就會記住，或到「設定」頁手動填 |

## 檔案在哪

```
芹查/
├─ 安裝芹查.cmd、啟動芹查.cmd
├─ desktop/                 電腦端（Node.js）
│  ├─ server/index.js       接收畫面、存片段和回報、網頁介面的 API
│  ├─ server/mcp.js         給 Claude Code 的 MCP 工具
│  ├─ server/store.js       資料存取（兩邊共用）
│  ├─ web/                  瀏覽器介面
│  ├─ tools/fake-phone.js   沒有手機時的模擬器（要 ffmpeg）：npm run fake-phone
│  └─ data/                 片段和回報（不進 git）
├─ ios/                     手機 app（SwiftUI＋螢幕廣播擴充，XcodeGen）
│  ├─ CeleryCheck/          app：掃 QR、開始投影、設定
│  ├─ Broadcast/            螢幕廣播擴充：把畫面壓成 JPEG 推到電腦
│  └─ Shared/               兩邊共用的設定
└─ docs/
```

測試錄影最多留 20 場，舊的自動刪掉；勾「保留」的、還有草稿沒送出的不刪。回報不會被自動刪。一場 10 分鐘的測試大約 300MB 到 500MB（畫面變動越多越大）。

## 限制

- 手機和電腦要在同一個區域網路。不在家時要投影，得兩邊都連同一個熱點
- iOS 的螢幕廣播不會顯示手指點在哪裡
- 畫面靜止時手機不會送新格，所以格數會掉，這是正常的
- 有些 app（例如播放有版權保護的影片）在廣播時會變黑畫面，這是 iOS 的限制
- 按鍵只在芹查的瀏覽器分頁是目前視窗時有作用（測試時把瀏覽器留在前景，眼睛看手機就好）
